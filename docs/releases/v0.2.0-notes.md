# PROGRAMARIS Tenancy v0.2.0

Second stable release of the PROGRAMARIS provider-neutral multi-tenant .NET integration SDK.

## NuGet packages

| Package | Target frameworks |
| --- | --- |
| `Programaris.Tenancy.Abstractions` | `netstandard2.0` |
| `Programaris.Tenancy` | `netstandard2.0`, `net10.0` |
| `Programaris.Tenancy.AspNetCore` | `net10.0` |
| `Programaris.Tenancy.Http` | `net8.0`, `net10.0` |

## New features

- Provider-neutral `ITenantStore` and `ITenantAccessValidator` contracts with explicit deny, inactive and unavailable outcomes.
- Optional ASP.NET Core authorization middleware with three distinct contexts: untrusted selection, registry validation and user authorization. Operation-scoped access checks.
- Endpoint-scoped host-defined browser/OIDC selection-source contract, candidate conflict/duplicate rejection, generic public failure rendering and fail-closed policies.
- Restricted outbound `HttpClient` package with explicit request-local propagation, exact-origin HTTPS allowlists, disabled redirects and no pooled cookies.
- Isolated .NET 8/.NET 10 NuGet consumers, eight-artifact manifest and SourceLink verification.

## Security and compatibility

Existing `ITenantContextAccessor.Current` remains **selected-only** and is not evidence of membership. The SDK has no embedded Identity authority, persistent tenant registry, default tenant or privilege bypass. Consumers implement their own trusted adapters, data isolation and endpoint authorization. Unity Mono/IL2CPP has not been certified; these NuGet packages do not constitute deployment certification of Gateway/Identity.

## Release integrity

The release carries four `.nupkg`, four `.snupkg` and `release-manifest.json` with the full source SHA and SHA-256 hashes of all eight artifacts. Publication uses a pinned successful tagged CI run and protected NuGet Trusted Publishing OIDC.
