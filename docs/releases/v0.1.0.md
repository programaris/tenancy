## Evidence register

### E01

[CI #39310256674](https://github.com/programaris/tenancy/actions/runs/39310256674):
both Windows and Ubuntu completed restore, Release build, .NET tests,
distribution validation and Python tests. Windows also executed the
end-to-end PowerShell validation script. This certifies the development
source SHA above, not the final release tag.

### E02

[HTTP tenancy tests](https://github.com/programaris/tenancy/blob/3b76ab704f0afb82c70a7cebf9f2d86f25c2c2d4/tests/Programaris.Tenancy.AspNetCore.Tests/HttpTenancyTests.cs)
cover missing, malformed and duplicated headers, explicit
`AllowMissingTenant()`, sequential/concurrent tenant isolation and
opt-in propagation rejecting existing headers.
The [middleware](https://github.com/programaris/tenancy/blob/3b76ab704f0afb82c70a7cebf9f2d86f25c2c2d4/src/Programaris.Tenancy.AspNetCore/TenantResolutionMiddleware.cs)
has no implicit tenant fallback or global opt-out.
These tests do not constitute user-to-tenant authorization.

### E03

[ADR-0003](../adr/0003-explicit-tenant-context.md) requires explicit selection;
[trust boundaries](../security/trust-boundaries.md) place authentication,
membership authorization and data isolation on consumers.
[Compatibility policy](../compatibility.md) explicitly withholds
Unity Mono/IL2CPP certification. Gateway and Identity integration
are separate initiatives, **not prerequisites** for SDK v0.1.0.

### E04

[NuGet package verifier](https://github.com/programaris/tenancy/blob/3b76ab704f0afb82c70a7cebf9f2d86f25c2c2d4/eng/verify_packages.py)
checks the exact three `.nupkg` and three `.snupkg` artifacts,
supported TFMs, allowed and synchronized dependencies, embedded PDBs,
README, Apache-2.0 license, authors, repository metadata and the PNG icon.
[Verifier tests](https://github.com/programaris/tenancy/blob/3b76ab704f0afb82c70a7cebf9f2d86f25c2c2d4/eng/test_verify_packages.py)
include expected rejection cases. SourceLink correctness in the actual
PDBs is a **separate pending requirement**.

### E05

[Independent NuGet smoke consumers](https://github.com/programaris/tenancy/blob/3b76ab704f0afb82c70a7cebf9f2d86f25c2c2d4/eng/smoke_consumer.py)
restore from the generated NuGet feed into isolated caches.
Ubuntu CI passed a `net10.0` consumer of the ASP.NET Core package
and a `net8.0` consumer selecting portable `netstandard2.0` assemblies.
This does not certify Unity runtime compatibility.

### E06

[Manifest generator](https://github.com/programaris/tenancy/blob/3b76ab704f0afb82c70a7cebf9f2d86f25c2c2d4/eng/create_artifact_manifest.py)
records the full source SHA and SHA-256 hashes of exactly six artifacts.
The Ubuntu CI uploaded `release-manifest.json` with the development
packages. This confirms creation of the manifest, **not** independent
review of hashes for a future release candidate. CI artifacts expire.
