# PROGRAMARIS Tenancy v0.1.0

First stable public release of the PROGRAMARIS multi-tenant .NET integration SDK.

## Packages

| NuGet package | Target frameworks |
| --- | --- |
| `Programaris.Tenancy.Abstractions` | `netstandard2.0` |
| `Programaris.Tenancy` | `netstandard2.0`, `net10.0` |
| `Programaris.Tenancy.AspNetCore` | `net10.0` |

## Features

- Portable `TenantContext` and `ITenantContextAccessor` contracts.
- Canonical tenant slug validation (lowercase ASCII, 1–63 characters).
- ASP.NET Core `X-Tenant` header selection with fail-closed behavior.
- `AllowMissingTenant()` for explicitly tenant-independent endpoints.
- Explicit downstream HTTP propagation without overwriting existing tenant headers.
- No implicit tenant, no fallback to a platform-owned tenant, and no global tenant opt-out.
- Isolated NuGet consumers in .NET 8 and .NET 10.
- SourceLink, portable PDB symbols and SHA-256 provenance checks.

## Scope and security

The SDK selects and transports a tenant; it **does not authenticate or
authorize** access to that tenant. Membership validation, tenant registry,
data isolation and authorization remain consuming-application obligations.

Unity Mono and IL2CPP runtime support is not certified in this version.
Worker scopes, persistence filters and administrative multi-tenant access
are not included.

## Release integrity

GitHub Release includes three `.nupkg`, three `.snupkg` files and
`release-manifest.json` with the source SHA and SHA-256 hashes.
All artifacts are certified by the tagged CI build and independently
verified before NuGet.org publishing.
